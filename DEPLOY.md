# Deploying Ment to Render

Ment is a monorepo with two services:

| Service | Path | Type |
|---------|------|------|
| **ment-api** | `backend/` | Node.js web service (Express + Prisma) |
| **ment-frontend** | `frontend-app/` | Static site (React CRA) |
| **ment-db** | — | Render PostgreSQL (free tier) |

## Prerequisites

1. Git repo pushed to GitHub: `https://github.com/Beknazar007/ment-bek`
2. A [Render](https://render.com) account

## One-click Blueprint deploy

1. Open the Blueprint link:

   **https://dashboard.render.com/blueprint/new?repo=https://github.com/Beknazar007/ment-bek**

2. Connect your GitHub account if prompted.
3. Review the three resources (`ment-api`, `ment-frontend`, `ment-db`).
4. JWT secrets are auto-generated by Render (`generateValue: true`).
5. Click **Apply** to create all services and deploy.

## What happens on deploy

### Backend (`ment-api`)

- Installs dependencies, generates Prisma client, compiles TypeScript
- Runs `prisma migrate deploy` against the Render Postgres database
- Starts on `0.0.0.0:$PORT` with a public `/health` endpoint
- CORS allows the frontend URL via `FRONTEND_URL` (wired automatically)

### Frontend (`ment-frontend`)

- Builds the React app with `REACT_APP_API_URL` pointing at the API service
- Serves static files with SPA fallback routing (`/* → /index.html`)

### Database (`ment-db`)

- Render managed PostgreSQL (free tier — expires after 90 days on free plan; upgrade for persistence)

## Environment variables

| Variable | Service | Set by |
|----------|---------|--------|
| `DATABASE_URL` | ment-api | Render Postgres (auto) |
| `JWT_ACCESS_SECRET` | ment-api | Auto-generated |
| `JWT_REFRESH_SECRET` | ment-api | Auto-generated |
| `FRONTEND_URL` | ment-api | Frontend service URL (auto) |
| `REACT_APP_API_URL` | ment-frontend | API service URL (auto) |
| `NODE_ENV` | ment-api | `production` |

## Local development

The database provider is **PostgreSQL** (required for Render). Use a local Postgres instance:

```bash
# Start local Postgres (Docker example)
docker run --name ment-postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=ment -p 5432:5432 -d postgres:16

# Backend
cd backend
cp .env.example .env
# Edit DATABASE_URL to: postgresql://postgres:postgres@localhost:5432/ment?schema=public
npm ci
npx prisma migrate dev
npm run dev

# Frontend (separate terminal)
cd frontend-app
npm ci
npm start
```

## Validate Blueprint locally

```bash
render blueprints validate render.yaml
```

## Post-deploy checklist

1. Open `https://<ment-frontend>.onrender.com` — landing page loads
2. Register a new user account
3. Confirm API health: `https://<ment-api>.onrender.com/health` → `{ "status": "ok" }`
4. Log in and browse mentors

## Notes

- **Free tier spin-down**: API and frontend sleep after 15 min of inactivity; first request may take ~30s.
- **Free Postgres**: Database expires after 90 days on free plan — export data or upgrade before expiry.
- **Demo users**: `devBootstrap` only runs when `NODE_ENV !== "production"`. Create accounts via `/register` in production.
